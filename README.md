# myWedJune2026
## Mô tả
Đây là ứng dụng CRUD quản lý sinh viên đăng ký môn học được xây dựng bằng Node.js và MySQL.

## Công nghệ sử dụng

* Node.js
* Express
* MySQL
* mysql2

## Cơ sở dữ liệu

Database: STUDENTSREG

Bảng sử dụng: STUDENT_ENROLEMENT

## Chức năng

### READ

GET /api/localdb

### CREATE

POST /api/student

### DELETE
